# Geoquiz

A geography quiz website. Guess countries from their flags, or name their capitals.

## Run it on your computer

You need [Node.js](https://nodejs.org) (the LTS version) installed once.

In a terminal, inside this folder:

```bash
npm install     # first time only, and after pulling changes that add packages
npm run dev     # starts the site
```

Then open http://localhost:3000 in your browser. Stop the site with `Ctrl+C` in the terminal.
